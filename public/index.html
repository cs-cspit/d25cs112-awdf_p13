    🔒 Security & Responsible AI Architecture

    • Server-Side Secret: API Key is strictly stored in .env on the Express backend and is never exposed in browser network requests.
    • Graceful Degradation: If the AI API fails, times out, or has an invalid key, the app catches the error and generates a template suggestion without crashing.
    • Rate Limiting: Enforces a maximum of 5 AI calls/minute per user to prevent quota exhaustion.
    • Human in the Loop: Output is presented as an editable suggestion, never forced upon the user.
